# Security Policy

## Supported Versions

Security fixes are applied to the current default branch and the latest published release. Older development snapshots are not maintained separately.

## Reporting a Vulnerability

Do not open a public issue for an undisclosed vulnerability. Use GitHub's private vulnerability reporting or security advisory feature for this repository. Include affected versions, reproduction steps, impact, and any proposed mitigation.

You should receive an acknowledgement within seven days. Maintainers will coordinate validation, remediation, and disclosure timing with the reporter.

Scientific accuracy issues and numerical parity regressions are important bugs, but they are not security vulnerabilities unless they create a security impact such as arbitrary code execution, unsafe file handling, or command injection.
